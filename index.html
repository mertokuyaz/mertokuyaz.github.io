How Bitcoin Mining Works

Think of Bitcoin mining as a giant, competitive lottery where miners try to find a "winning number" to validate a new block of transactions. This process, called Proof-of-Work, secures the network without a central authority.

  • The Block: A collection of recent, unconfirmed transactions. Miners gather these into a potential block.
  • The Hash: A miner takes the block's header data and runs it through a one-way function called SHA-256. This produces a unique, fixed-length digital fingerprint called a "hash".
  • The Nonce: Since the block data is fixed, miners add a special number called a nonce (number used once). Even a tiny change to the nonce results in a completely different hash.
  • The Difficulty Target: The Bitcoin network sets a "difficulty target". To win, a miner must find a hash that is numerically less than this target. This is represented here as a required number of leading zeros.

How This Simulator Works

This tool mimics the core "guessing" loop of the mining process right in your browser.

  • Block Data: The text in this box simulates the data a miner would hash. You can change it to see how it affects the final hash.
  • Nonce (Behind the Scenes): When you click "Start Mining," the script starts at nonce = 0, combines it with the Block Data, and calculates the SHA-256 hash.
  • The Loop: If the hash doesn't meet the selected Difficulty, it increments the nonce (0, 1, 2, 3...) and tries again, thousands of times per second.
  • Hashes/sec: This metric shows how fast your computer is performing this guess-and-check loop. Real miners use specialized hardware (ASICs) that can perform trillions of hashes per second.
  • ETA: Based on the current hash rate, this gives a statistical estimate of how long it might take to find a winning hash.
