Blockchain tampering lab

Create demo blocks or mine your own, then edit an earlier block. Its hash changes, breaking the next block's stored link. Repairing re-mines the affected blocks in order.

Demo blocks use 2 leading zeros for quick experiments. This local chain has no network consensus; real Bitcoin also requires competing with the network's accumulated work.

Miner race

Probability simulation

Set three miners' relative hash power and run 30 rounds. A miner with twice the power has twice the chance per round, but can still lose.

This is a mathematical model, not a hardware benchmark. Each miner gets an independent random waiting time; the first wins. Bars show observed win shares, not progress toward finding a hash. Small samples can differ from expected probabilities.
